# telemetry-solution/data

This folder contains the JSON files for the Telemetry specification for Arm IP based products.

Supported Data:

- PMU events, metrics and methodology for a selection of Arm CPUs that support Arm Telemetry Solution.
- Derived (not official) CPU specifications for cores without a published one, in `pmu/cpu/specifications/derived`. See its README for provenance.
- PMU events, metrics and methodology for a selection of Arm CMNs that support Arm Telemetry Solution.
